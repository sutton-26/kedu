刻度 · Kedu

一个把大脑外置的微型记录软件。单文件 HTML、零依赖、纯本地、无账号、无网络。用来记下正在做什么，把记忆负担从人脑移走。

核心理念

  1. 大脑负责想事，不负责记事。用「链条」按时间顺序记录一天的流水，抬眼就能接上刚才的线头。
  2. 一件事只处理三次：优先级矩阵决定要不要做，日历决定什么时候做，记录决定做得怎么样。
  3. 有始有终。每个任务只有三个记录字段：进展 / 难点 / 收获。任务中止时必须留下收获。
  4. 数据归用户。无账号、无云同步、无遥测，数据只在本机。

它刻意不做什么

不做知识库（无标签、无多层目录、无双向链接）；不做强提醒（无推送、无通知、无打卡积分）；不做协作（无账号体系、无同步、无分享）；不做通用笔记（记录必须挂在任务上）。

四个页面

优先级：四象限（紧急 × 重要），全系统唯一数据入口，可归档但仍在日历 / 链条 / 记录中保留。时间：月 / 年日历，任务可排多天，拖动事项池到格子即完成排期。链条：一天的流水记录，左侧时间线、右侧长期链，已排期任务作为标签关联到记录。记录：按项目分组查看每个任务的进展 / 难点 / 收获。

今日链路小窗

入口是链条页的小窗图标或快捷键 Alt + L。形态为屏幕面积 1/16 的 9:16 竖版窗口，常驻角落、可拖拽改变大小。标题栏图钉是置顶开关：亮 = 总在最前，灭 = 取消置顶但不关闭窗口。小窗与主窗口共用同一份数据，即时同步。

怎么用

浏览器版：双击本文件用 Chrome / Edge 打开即可，无需安装与联网。上手顺序：优先级页点「+ 添加」写第一件事放进四象限，到时间页拖到今天，在链条页随手记下现在在干什么，做完后到记录页写下进展 / 难点 / 收获。

数据

浏览器版存于 localStorage，键名 kedu.v2；桌面版存于 %APPDATA%\kedu-desktop。目前没有导出 / 备份功能。许可：MIT。
